# Data Classification

## Levels
Public, Internal, Confidential, and Restricted. Default classification is Internal unless marked otherwise.

## Handling Restricted data
Restricted data (credentials, personal data, financial records) requires encryption at rest and in transit, access logging, and explicit owner approval for sharing.

## Labeling
Documents must carry their classification in the header or metadata. Unlabeled files in shared drives are flagged for review.
