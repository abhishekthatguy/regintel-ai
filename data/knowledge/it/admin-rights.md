# Local Admin Rights

## Default posture
Employees do not receive local admin rights by default. Standard installs run through the software portal with elevated service accounts.

## Requesting elevation
Temporary elevation (up to 8 hours) is granted via the self-service elevation tool after an access ticket. Persistent elevation requires security approval and is reviewed quarterly.

## Audit
All elevation events are logged and reviewed weekly by the security team.
