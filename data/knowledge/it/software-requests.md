# Software Installation

Approved software installs from the self-service software portal without a ticket.

## Non-catalog software
Software not in the catalog requires: a software request ticket, manager approval, and a security review (2-5 business days).

## Prohibited
Peer-to-peer clients, unlicensed tools, and crypto-mining software are prohibited and auto-blocked.
